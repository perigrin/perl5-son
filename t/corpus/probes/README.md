# Probe programs, 2026-10 (raw)

These are the programs written to check each shape chalk learned to lower
(B::SoN -> chalk -> lli, compared with perl). They were kept in a session
scratchpad and saved here so they are not lost. Names are
`<scratch subdir>-<file>.pl`.

They are raw material, not yet corpus cases. Some are known WRONG on purpose
(ar, ar2, ar3, s5, a8, d0). Some duplicate each other. The plan (see
docs/memory/roadmap-simple-perl-static-compiler.md, step 4) is to cut minimal
cases from these into an idioms corpus that has its own census and ratchet.
